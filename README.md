# Ingeniería del Software 3 - Práctico 2025

Repositorio Git de Ingeniería de Software 3 - 2025

---

## 📋 Agenda del Curso

Durante este curso, exploraremos herramientas y conceptos esenciales para el desarrollo y la gestión de sistemas modernos:

1. **Git Básico**  
   Introducción a Git, la herramienta de control de versiones más utilizada. Aprenderemos conceptos fundamentales y operaciones básicas para gestionar y colaborar en proyectos de software.

2. **Docker**  
   Plataforma para desarrollar, enviar y ejecutar aplicaciones en contenedores. Veremos cómo crear y gestionar contenedores y mejores prácticas para entornos de desarrollo y producción.

3. **Azure y Azure DevOps**  
   Uso de servicios de Microsoft Azure y Azure DevOps para desplegar y gestionar aplicaciones en la nube. Se incluyen herramientas de CI/CD para automatizar procesos de desarrollo y despliegue.

4. **Introducción a Sistemas Distribuidos y Arquitectura de Microservicios**  
   Implementación de soluciones distribuidas y contenerizadas aprovechando capacidades de escalabilidad y resiliencia.

5. **Pipelines de Build y Deploy**  
   Configuración y gestión de pipelines para mantener calidad y consistencia en el desarrollo. Automatización de procesos para reducir errores humanos.

6. **Pruebas Unitarias y de Integración**  
   Escritura y ejecución de pruebas automatizadas para asegurar robustez y correcto funcionamiento del código.

---

## 🎯 Enfoque de la Materia

El objetivo principal es **comprender los conceptos de integración y entrega continua (CI/CD), automatización y despliegue**, más que dominar una herramienta específica. Se espera que el estudiante pueda complementar los conocimientos con documentación oficial o recursos externos.

- Se permite y alienta el uso de **IA** para generar scripts, configurar pipelines y optimizar tareas, siempre que se comprenda lo implementado.  
- Los trabajos prácticos pueden usar cualquier nube pública y herramienta de CI/CD, aunque se enfocará en **Azure DevOps y Microsoft Azure**.

> Para estudiantes que quieran usar Azure:  
> Cuenta gratuita: [https://azure.microsoft.com/es-es/free/students](https://azure.microsoft.com/es-es/free/students)

⚠️ Importante: si se usa cuenta estándar, el alumno debe asegurarse de usar solo servicios gratuitos para evitar cargos.

## 📦 Condiciones para la Presentación de Trabajos Prácticos

**Formato de entrega:**

- Repositorio Git con todas las ramas, commits y tags solicitados.
- Archivo `decisiones.md` con justificaciones técnicas.
- Repositorio correctamente configurado y accesible.

**Tiempo de entrega:**

- Revisiones semestrales cada 4 semanas.
- Trabajos del 1 al 4: semana 5.  
- Trabajos del 5 al 8: semana 9.  
- Defensa oral obligatoria para aprobar.  

**Criterios de evaluación:**

- Organización técnica del repositorio: 30%
- Claridad y justificación en `decisiones.md`: 30%
- Defensa oral: 40% (obligatoria para aprobar)

## 🏗 Trabajo Práctico Integrador: Requisitos y Validación

**Requisitos del proyecto:**

1. Aplicación completa con:
   - Servicio de frontend
   - Servicio de backend
   - Interacción con base(s) de datos
   - Repositorio público Git

2. Build y deploy automatizados:
   - Cada PR aprobado debe construir la aplicación automáticamente.
   - Ejecutar tests unitarios y recolectar resultados.
   - Deploy automático a QA tras superar tests.
   - Aprobación manual antes de pasar a producción.

3. Presentar **test cases** escritos, incluyendo tests de integración.

**Validación del proyecto:**

- El profesor pedirá cambios pequeños en código y tests para comprobar:
  - Ejecución de pruebas unitarias y reporte.
  - Ejecución de build y deploy automatizado.
  - Reflejo de cambios en QA.
  - Ejecución de pruebas de integración.
  - Aprobación manual para producción.
